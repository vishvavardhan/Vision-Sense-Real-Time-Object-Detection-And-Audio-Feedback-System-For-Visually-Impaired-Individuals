# Real-Time Object Detection for Visually Impaired Individuals

An technology system that uses **YOLO (You Only Look Once)** and the **COCO dataset** to detect and classify objects in real time and provide **auditory feedback** to visually impaired users.

The system processes both **static images and live video streams**, identifies objects in the user's surroundings, and converts detected object information into speech. By combining **deep learning, computer vision, and text-to-speech technology**, the project aims to improve environmental awareness, mobility, and independence for people with visual impairments.

## Key Features

* Real-time object detection using YOLO
* Object classification using the COCO dataset
* Support for images and live video feeds
* Bounding-box based object localization
* Text-to-speech audio announcements
* Fast and accurate detection
* Assistive interface designed for visually impaired users

## Technology Stack

**Python • YOLO • OpenCV • COCO Dataset • Deep Learning • Computer Vision • Text-to-Speech**
